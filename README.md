# KineticType: SVG Path Text Animator & CSS Generator

KineticType is an advanced, responsive browser utility designed for web developers and UI designers. It allows you to create fluid typographic animations along custom SVG bezier curves, preview motion in real-time, and instantly export production-ready SVG and CSS code snippets.

## Features

- **Interactive Canvas Sculpting**: Drag path start, end, and control points directly on the stage to instantly bend text along custom curves.
- **Preset Library**: Quickly jump between smooth wave, arch, loop, and flat line archetypes.
- **Live Kinetic Controls**: Tweak font size, letter spacing, font family, text color, animation speed, and direction seamlessly.
- **Production Code Export**: Copy clean, accessible SVG markup and CSS keyframe animation rules with a single click.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or server setups required (fully static frontend utility).

## Technologies

- Vanilla HTML5 Semantic Elements
- CSS3 Variables & Flexbox/Grid Responsive Layout
- Modern Vanilla JavaScript (ES6+ SVG Path Manipulation & Drag-and-Drop Handlers)
